## 🚀 Projects Deep Dive

### 🌐 [Task 2: SYNAPSE OS — Spatial Neural Landing Page](file:///d:/AMINE2/COURS%20FAC/travaux/PROGREE_INTERNSHIP/Frontend/Task%202/)

A product marketing landing page built strictly with semantic HTML5 and vanilla CSS/JS.

#### 💡 Highlights:
- **Clean Semantic Structure**: Accessible `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<aside>`, and `<footer>` elements with ARIA compliance.
- **Zero-Overflow Responsive Layouts**: Fluid typography via `clamp()`, flexible CSS Grid/Flexbox modules, and defensive boundaries across 5 device breakpoints (Ultrawide, Laptop, Tablet Landscape, Tablet Portrait, Mobile).
- **Interactive Features**:
  - **Live Neural Sandbox**: Tune temperature, node parameters, and simulate execution logs in real time.
  - **Interactive ROI Calculator**: Dynamic slider computing annual cloud savings and unlocked engineering hours.
  - **Command Palette (`Ctrl+K`)**: Keyboard-driven quick navigation.
  - **Ambient Particle Backdrop**: Dynamic canvas particle connection network.
  - **Billing Switcher**: Real-time monthly vs annual pricing discount toggles.

---

### 🌦️ [Task 3: AETHERIA LIVE — Worldwide Weather Portal](file:///d:/AMINE2/COURS%20FAC/travaux/PROGREE_INTERNSHIP/Frontend/Task%203/)

A real-time meteorological portal fetching atmospheric data dynamically via asynchronous REST APIs.

#### 💡 Highlights:
- **Dual REST Architecture**:
  - **Open-Meteo REST API (Default)**: Zero-config, reliable global weather, air quality indices (AQI PM2.5/PM10/Ozone), and hourly/daily telemetry.
  - **OpenWeatherMap Integration**: Modal configuration allowing custom API key testing.
- **Atmospheric Particle Engine**: Canvas dynamically simulating condition effects (rain with splash trajectories, drifting snowflakes, warm solar lens flare rays, starry night skies, thunderstorm lightning).
- **Interactive Synoptic Map**: Embedded Leaflet map with multiple tile sets (Standard, Satellite, Night Dark).
- **Dynamic 24-Hour Bezier Curve**: Interactive curve graph switching between temperature, precipitation probability, and wind speed.
- **Telemetry Metric Matrix**: Compass wind vectors, UV index gauge, barometric pressure trend, solar sun arc trajectory, and lifestyle activity advisories (running, cycling, clothing recommendations).

### 📊 [Task 4: APEXMETRICS ENTERPRISE — Reactive Business Analytics Portal](file:///d:/AMINE2/COURS%20FAC/travaux/PROGREE_INTERNSHIP/Frontend/Task%204/)

An enterprise-grade analytical administration dashboard featuring reactive chart objects, client-side SPA routing, and live simulated telemetry.

#### 💡 Highlights:
- **Custom SPA Hash Router**: Seamless transitions between 7 functional views (*Executive Dashboard*, *Deep Analytics*, *Treasury & Finance*, *Enterprise Tenants*, *Cluster Health*, *Compliance Reports*, *Settings*).
- **Reactive Chart.js Integration**: Dynamic Line/Bar toggle charts, ARR acquisition doughnut, departmental SLA radar matrices, and live throughput sparklines.
- **Multi-Theme Engine**: 4 palettes (*Midnight OLED*, *Clean Light*, *Cyber Neon*, *Royal Slate*) with synchronized chart color updates and Web Audio API telemetry chimes.
- **Enterprise Matrix Data Table**: Real-time multi-column search & sort, status/region filters, tenant dossier drilldown modals, and CSV/JSON export engines.
- **Live Stream Simulator**: Real-time background ticker mimicking incoming cluster events and live ARR increments.
- **FY27 Growth Simulator**: Interactive forecasting sliders with celebration particle effects.

## ⚡ Quick Start / Local Setup

Each project is designed to run in any modern web browser. For projects utilizing ES6 JavaScript Modules (Task 4) or dynamic map tiles (Task 3), serving via a local HTTP server is recommended:

```bash
# Clone or open the repository in terminal
cd Frontend

# Serve using Python 3
python -m http.server 8080

# Or serve using Node.js
npx serve .
```

Once running, navigate to:
- **Task 2**: `http://localhost:8080/Task%202/`
- **Task 3**: `http://localhost:8080/Task%203/`
- **Task 4**: `http://localhost:8080/Task%204/`
