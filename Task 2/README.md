# SYNAPSE OS — Next-Generation Spatial Neural Marketing Landing Page

An ultra-modern, semantic, high-performance, single-page marketing landing page for **SYNAPSE OS** (The Autonomous Spatial Neural Workspace & AI Coprocessor).

Built strictly with clean semantic HTML5, pure CSS3 (custom design system, Grid & Flexbox, fluid typography), and vanilla JavaScript.

---

## 🌟 Highlights & Features

1. **Semantic HTML5 Mastery & Accessibility**:
   - Proper landmark structure: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<aside>`, `<footer>`.
   - Accessible ARIA attributes (`aria-expanded`, `aria-label`, `aria-hidden`, `role="region"`).
   - Rich OpenGraph & SEO meta tags.

2. **Custom CSS Design System & Visual Polish**:
   - **Zero Frameworks**: 100% custom CSS tokens, typography, and layout logic.
   - **Fluid Typography**: Responsive font sizing using `clamp()`.
   - **Modern Glassmorphism & Cyber Aesthetics**: Backdrop blurs, animated gradient text, glowing neon mesh cards, 3D tilt interaction.
   - **Strict Zero Horizontal Overflow**: Defensive styling ensuring no horizontal scrollbars on any viewport size.

3. **Explicit Responsive Breakpoints**:
   - **Desktop / Ultrawide**: `> 1200px` (Multi-column feature & pricing grids, HUD visualizer).
   - **Small Laptops / Tablets Landscape**: `max-width: 1024px` (2-column adapted layouts).
   - **Tablets Portrait**: `max-width: 768px` (Mobile drawer navigation, stacked sandbox).
   - **Mobile Phones**: `max-width: 480px` (Touch-friendly stacked controls, simplified actions).
   - **Ultra-compact Screens**: `max-width: 360px` (Fluid scaling preventing cutoff).

4. **Rich Interactive Vanilla JS Engine**:
   - **Ambient Dynamic Particle Canvas**: Interactive ambient backdrop with animated particle connections.
   - **Interactive Live Neural Sandbox**: Preset selection, real-time node count & temperature tuning, speculative vs deterministic mode toggle, and live simulated execution with streaming logs.
   - **Real-Time ROI / Efficiency Calculator**: Live slider calculations for annual cloud cost savings and engineering hours unlocked.
   - **Command Palette (`Ctrl+K` / `Cmd+K`)**: Fast keyboard-navigable section search modal.
   - **3D Tilt Interaction**: Mouse perspective rotation on featured cards.
   - **Interactive Pricing Switcher**: Dynamic Monthly vs Annual billing switch (25% discount).
   - **Animated Metric Counters**: IntersectionObserver counting up numbers on scroll.
   - **Testimonials Carousel**: Touch swipe support, autoplay, dot indicators, and pause-on-hover.
   - **Light / Dark Mode Switcher**: Persisted locally in `localStorage`.
   - **Toast Notifications**: Interactive feedback on newsletter submission, plan selection, and clipboard copy.
